## What was built
- `packages/model/src/widgets.ts`: a `WidgetSchema` for all 29 type names. That's 28 widgets plus `stocks`, an alias of
  `markets`. Each has label, category (prototype), fields, defaults, help and refresh (D-58). `fields.ts` has the field
  kinds and the zod builder.
- Schema v2: every Glance type is modelled; widget zod schemas, import, generation and the unknown-key check are derived
  from the registry (ADR-0017). Draft migration v1 → v2.
- `rules.ts`: `field.required` (Glance-enforced fields), reddit template and app-auth, releases source prefix,
  custom-api string body, nesting from `disallowedChildren`.
- Validation stand-ins for placeholders in checked fields (enum option, time zone, reddit template).
- `scripts/glance-source-data.ts` → `packages/model/src/glance-source.generated.ts` (type names, built-in themes).

## Refresh per type (D-58), from the v0.8.6 source
- **Interval** (`cache` overrides it):
  - 15 s: server-stats
  - 1 m: docker-containers
  - 5 m: monitor
  - 10 m: dns-stats, twitch-channels, twitch-top-games
  - 30 m: hacker-news, reddit, extension
  - 1 h: markets/stocks, lobsters, videos, repository, change-detection, custom-api
  - 2 h: releases, rss
- **On the hour** (`cache` ignored): weather, calendar-legacy.
- **None** (`cache` ignored): clock, calendar, to-do, bookmarks, search, iframe, html, group, split-column.

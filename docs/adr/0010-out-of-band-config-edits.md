# 0010. Handling hand edits to the generated glance.yml

- **Status:** superseded by ADR-0016 (design D-32)
- **Date:** 2026-10-13
- **Decider:** PM
- **UX impact:** **yes**. It decides what you see if the file was changed outside the editor.

## Context
The brief says nobody edits the generated YAML by hand. In practice it can still happen (an emergency fix, an
old script, `glance.yml.prev` restored by hand). Overwriting such changes silently loses work, but so does
blocking the save forever.

## Options
### A. Detect and ask (recommended)
The editor stores the sha256 of what it last wrote. On Save (and on opening the editor), if the live file differs:
show a banner with a diff and three choices: **Overwrite** (the editor wins), **Re-import** (run the import, ADR-0011,
into a new revision for review), or **Cancel**.
### B. Always overwrite silently
### C. Refuse to save until the file matches

## Recommendation
**A.** The generated file also starts with a header comment: "Generated by Glance Editor vX. Do not edit. Changes will be overwritten."

## Verified vs assumed
- Verified by test (2026-10-13, v0.8.6): a config starting with a `# Generated by …` comment passes `config:validate`.

## Superseded (2026-10-13, ADR-0016)
Design D-32: if the file changed on disk since the draft began, Save asks **keep the draft** (the outside version is stored first) **or load the file**. The header comment idea is kept only for files the editor creates from scratch, since D-38 keeps an imported file's own look.

## Decision record
**Accepted 2026-10-13 by the PM (via chat)**: option A (detect by hash; overwrite / re-import / cancel) plus the generated-file header comment.
